# Bloc 5 — Industrialisation d’un algorithme d’apprentissage automatique

## Objectif
Rendre le modèle utilisable en production.

## Ce qu’il faut faire

### 1. Standardisation
- Sauvegarde du modèle
- Gestion des dépendances
- Configuration du projet

### 2. Création d’une API
- Endpoint de prédiction
- Upload d’image
- Retour du résultat

### 3. Déploiement
- Dockerisation
- Hébergement (local ou cloud)

### 4. Interface utilisateur
- Interface simple pour tester
- Résultat compréhensible

### 5. Automatisation
- Pipeline de prédiction
- Logs

## Livrables attendus
- API fonctionnelle
- Application web ou interface
- Dockerfile

## Technologies recommandées
- FastAPI / Flask
- Docker
- Streamlit
