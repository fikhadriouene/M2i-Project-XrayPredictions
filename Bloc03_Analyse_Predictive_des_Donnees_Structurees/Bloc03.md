# Bloc 3 — Analyse prédictive de données structurées

## Objectif
Mettre en place des modèles de machine learning sur des données structurées.

## Ce qu’il faut faire

### 1. Préparation des données
- Encodage des variables
- Normalisation
- Split train / test

### 2. Modélisation supervisée
- Choisir des algorithmes :
  - Régression logistique
  - Random Forest
  - SVM
- Entraîner les modèles

### 3. Modélisation non supervisée (optionnel)
- Clustering (KMeans)
- Réduction de dimension (PCA)

### 4. Évaluation des performances
- Accuracy
- Precision / Recall
- F1-score
- ROC-AUC

### 5. Optimisation
- Ajustement des hyperparamètres
- Gestion du déséquilibre

## Livrables attendus
- Pipeline de ML
- Comparaison de modèles
- Rapport de performance

## Technologies recommandées
- Scikit-learn
- Pandas
