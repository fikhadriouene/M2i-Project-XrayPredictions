# Bloc 6 — Direction de projets de gestion de données

## Objectif
Piloter un projet data de bout en bout.

## Ce qu’il faut faire

### 1. Définition du besoin métier
- Identifier le problème
- Traduire en problème data

### 2. Cahier des charges
- Objectifs
- Contraintes
- Livrables

### 3. Planification
- Roadmap
- Planning
- Jalons

### 4. Suivi du projet
- Indicateurs de performance
- Suivi des tâches
- Gestion des risques

### 5. Communication
- Vulgarisation des résultats
- Présentation au métier
- Documentation

### 6. Pilotage global
- Coordination des étapes
- Prise de décision
- Vision globale

## Livrables attendus
- Cahier des charges
- Planning
- Présentation finale
- Documentation projet

## Technologies recommandées
- Notion / Trello
- PowerPoint / Canva
- GitHub
