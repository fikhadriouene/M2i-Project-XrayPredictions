# Bloc 4 — Analyse prédictive de données non structurées (Deep Learning)

## Objectif
Construire un modèle de deep learning pour analyser des images.

## Ce qu’il faut faire

### 1. Prétraitement des images
- Resize (ex : 224x224)
- Normalisation
- Conversion en matrices

### 2. Construction du modèle
- CNN (Convolutional Neural Network)
- ou Transfer Learning :
  - ResNet
  - EfficientNet
  - VGG

### 3. Entraînement
- Définir loss et optimizer
- Lancer l’apprentissage
- Sauvegarder les modèles

### 4. Optimisation
- Data augmentation
- Regularization
- Fine-tuning

### 5. Évaluation
- Accuracy
- Precision / Recall
- F1-score
- Courbe ROC

## Livrables attendus
- Modèle entraîné
- Courbes d’apprentissage
- Évaluation détaillée

## Technologies recommandées
- TensorFlow / Keras
- PyTorch
- NumPy
