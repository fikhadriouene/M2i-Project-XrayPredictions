# Bloc 2 — Analyse exploratoire, descriptive et inférentielle de données

## Objectif
Comprendre les données, détecter les problèmes et extraire des informations utiles.

## Ce qu’il faut faire

### 1. Nettoyage des données
- Gestion des valeurs manquantes
- Suppression des doublons
- Correction des incohérences

### 2. Analyse exploratoire (EDA)
- Distribution des classes (sain vs malade)
- Visualisation d’images
- Analyse des métadonnées (âge, sexe si dispo)

### 3. Analyse statistique
- Analyse univariée
- Analyse multivariée
- Corrélations entre variables

### 4. Analyse de qualité des données
- Détection d’images corrompues
- Vérification des labels
- Analyse du déséquilibre de classes

### 5. Visualisation
- Histogrammes
- Graphiques
- Exemples d’images

## Livrables attendus
- Notebook d’analyse exploratoire
- Graphiques explicatifs
- Rapport de qualité des données

## Technologies recommandées
- Pandas
- NumPy
- Matplotlib
- Seaborn
